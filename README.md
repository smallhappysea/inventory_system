## 项目简介
这是一个基于 Linux/C 的商品管理服务器，支持本地命令行管理和远程客户端网络查询。实现了商品的增删改查、库存入库、多线程并发处理客户端请求、文件持久化存储等功能。
## 技术栈
- **语言**：C11
- **网络**：TCP socket
- **并发**：POSIX 多线程，互斥锁保护共享文件
- **数据存储**：二进制文件（product.dat），自定义结构体 Product
- **构建工具**：GCC
- **版本控制**：Git
## 功能特性
- 本地命令行交互（增删改查、入库）
- 远程客户端网络查询：
	- 查询所有商品列表
	- 根据ID查询单个商品
	- 远程添加商品（带并发锁保护）
- 多线程服务器处理多个客户端
- 操作日志记录（operation.log）
## 编译运行步骤
### 编译本地管理程序
`gcc -o inventory main.c file_ops`
`-o`:是编译文件名可自拟
### 编译网络服务器
`gcc -o server server.c file_ops.c -phtread`
### 编译客户端
`gcc -o client client.c`
### 运行
1.启动服务器
`./server`
2.运行客户端
`./client`
3.本地管理系统
`./inventory`
### 环境要求
- Linux 操作系统（CentOS 7+ / Ubuntu 18.04+）
- GCC 编译器
## 客户端命令协议
#### 命令
|功能|说明|示例|
|--|--|--|
|list|查询所有商品列表|list|

|add,名称,价格,库存|添加新商品(可含空格)|add,苹果,100,21|

## 注意事项
- **确保没有其他程序占据8888端口**被占用可修改`sever.c`中的htons(8888)为其他端口
- 服务器和本地管理程序 **不要同时写 product.dat**，否则可能损坏数据。建议只运行一个写程序。
- 首次运行科用`./inventory`添加商品测试商品，再启动服务器。
